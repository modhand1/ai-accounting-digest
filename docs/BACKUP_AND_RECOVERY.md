# Автоматическое обновление и резервное копирование

## Что автоматизировано

1. Каждый PR и каждое изменение `main` запускают тесты и публичную проверку.
2. Резервный процесс читает только `origin/main`, поэтому локальные ветки и
   приватные материалы в архив не попадают.
3. При новом коммите создаются Git bundle, ZIP-снимок, манифест и SHA-256.
4. Все файлы повторно проверяются уже в папке назначения.
5. Если коммит не изменился, новый архив не создаётся.

Слияние PR остаётся отдельным решением владельца. Это единственная ручная
точка публикации.

## Рекомендуемое расположение

```text
Приватный архив проектов/
└── ai-accounting-digest/
    └── Автоматические резервные копии/
        ├── .backup-state.json
        └── 2026/
            └── 08/
                └── 2026-08-03_203000_0a5db14/
```

Папка назначения должна находиться вне Git-репозитория и иметь доступ только
у владельца Google-аккаунта.

## Первый ручной запуск

```powershell
python tools/backup_project.py `
  --repo . `
  --destination "G:\Мой диск\Приватный архив проектов\ai-accounting-digest\Автоматические резервные копии"
```

Программа выводит JSON со статусом `created`, `existing_verified` или
`unchanged`. Статус `error` означает, что состояние не было принято как
успешная резервная копия.

## Ежедневная задача Windows

После подключения Google Drive for desktop выполните один раз:

```powershell
powershell -ExecutionPolicy Bypass -File tools\install_backup_task.ps1 `
  -BackupDestination "G:\Мой диск\Приватный архив проектов\ai-accounting-digest\Автоматические резервные копии"
```

Установщик сначала создаёт и проверяет реальный архив. Если проверка не
проходит, задача Windows не регистрируется.

## Проверка восстановления

```powershell
python tools/restore_backup.py `
  "G:\Мой диск\Приватный архив проектов\ai-accounting-digest\Автоматические резервные копии\2026\08\<архив>"
```

Для фактического восстановления добавьте пустую папку:

```powershell
python tools/restore_backup.py "<архив>" --restore-to "C:\Recovery\ai-accounting-digest"
```

## Приватная RAG-база

RAG-корпус и рабочие выжимки не включаются в этот архив. Для них используется
отдельный закрытый Google Drive и отдельная периодическая копия на внешний
SSD. Не помещайте RAG-файлы в репозиторий даже временно.
