# ИИ × БУХГАЛТЕР

Конверсионный Flask-сайт с AI-дайджестом для бухгалтеров-новичков.

## Быстрый запуск

1. Откройте терминал в папке проекта.
2. Установите Flask:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Запустите сайт:

   ```powershell
   python app.py
   ```

4. Откройте в браузере `http://127.0.0.1:5000`.

## Где что находится

- `app.py` — маршруты сайта и обработка формы.
- `content.py` — базовые материалы и сборка общего каталога.
- `materials_advanced.py` — углублённые материалы №04–05.
- `materials_course.py` — материалы курса №02 и №06–10.
- `templates/` — HTML-страницы.
- `static/css/style.css` — дизайн и адаптивность.
- `static/js/main.js` — меню, анимации и счётчик формы.
- `static/images/` — фирменная графика.
- `data/requests.csv` — появится после первой заявки.

Чтобы добавить материал, скопируйте один словарь в подходящий модуль,
измените номер, уникальный `slug`, заголовок и текст. После изменения
проверьте, что номера и `slug` не повторяются.

## Публикация

Проект подготовлен для публикации на Linux-хостинге через Gunicorn. Пошаговая
инструкция и список обязательных настроек находятся в
[`PUBLICATION.md`](PUBLICATION.md).

## Безопасные изменения и резервные копии

Каждое изменение должно проходить через отдельную ветку и PR. GitHub
автоматически запускает тесты и проверку публичных границ. После слияния
проверенную копию `origin/main` можно автоматически сохранять в закрытую
папку Google Drive без включения локальных веток и приватных материалов.

Настройка, восстановление и правила хранения описаны в
[`docs/BACKUP_AND_RECOVERY.md`](docs/BACKUP_AND_RECOVERY.md).
