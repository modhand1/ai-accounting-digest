# Правила работы с публичным репозиторием

Этот репозиторий содержит только публичную версию проекта «ИИ × БУХГАЛТЕР».

## Обязательный процесс

1. Перед началом работы получить свежий `origin/main`.
2. Создать отдельную ветку `agent/<краткое-название>`.
3. Не записывать изменения напрямую в `main`.
4. Перед отправкой выполнить:
   - `python -m unittest discover -v`;
   - `python tools/check_public_repo.py`.
5. Создать Draft PR и перечислить изменённые файлы, проверки и исключённые
   приватные материалы.
6. Сливать PR только после отдельного решения владельца проекта.

## Что запрещено добавлять

- рабочие оригиналы, банковские формы, выгрузки и документы работодателя;
- ФИО, реквизиты, реальные суммы, контрагентов и закрытые инструкции;
- приватные исследования, редакционные аудиты и внутренние планы;
- RAG-корпус, папки Google Drive и локальные пакеты знаний;
- `.env`, ключи, токены, пароли, сертификаты и файлы учётных данных;
- архивы `.bundle`, `.zip`, `.7z`, резервные копии и `data/requests.csv`;
- абсолютные пользовательские пути вида `C:\Users\...`.

Безопасные методики создаются заново на синтетических данных. Статус
`public_safe` нельзя считать подтверждённым без отдельного решения владельца.

## Резервные копии

Резервный процесс читает только публичный `origin/main`. Он не должен включать
локальные ветки, рабочее дерево, приватные папки или RAG-материалы. Архивы
сохраняются вне репозитория в закрытом хранилище.
